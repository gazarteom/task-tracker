## Тема

**Task Tracker** — личный список задач со сроками и приоритетами.

Автор: Газ Артем Андреевич 
Группа: ФТ24ВР62ИВ

## Основной сценарий

Task Tracker помогает студенту вести личные задачи. Пользователь добавляет задачу, указывает срок и приоритет, меняет статус и находит просроченные записи. Теги помогают группировать задачи.

## Стек

- React
- TypeScript
- Vite
- React Router
- Supabase (справочник тегов)
- позже: Node.js, Express, Supabase Auth

## Версия Node.js

`24.15.0` (файл `.node-version` в корне репозитория)

## Что работает сейчас (ЛР 5)

- Создание, просмотр, изменение и удаление задач
- Одна форма для создания и редактирования, отмена без сохранения
- Проверка названия, срока и описания у завершённой задачи
- Фильтр списка по статусу
- Справочник тегов читается из Supabase, не из JSON
- Состояния загрузки, ошибки и пустого справочника
- Кнопки «Повторить» и «Обновить справочник» без потери черновика
- Пока тег не выбран или справочник недоступен, сохранить нельзя

В задаче хранится `id` тега (`study`), в списке выбора показывается `name` («Учёба»). Основные записи по-прежнему живут только в памяти вкладки: после обновления страницы возвращаются пять демонстрационных задач. Постоянным в этой работе становится только справочник.

## Схема базы

| Таблица | Назначение | Ключ | Связь | Доступ |
| --- | --- | --- | --- | --- |
| `tags` | публичный справочник тегов | `id` text | на него ссылается `tasks.tag_id` | чтение для `anon` и `authenticated` |
| `tasks` | личные задачи | `id` uuid | `owner_id` → `auth.users`, `tag_id` → `tags` | закрыта до ЛР 6, RLS включён, прав нет |

Поле `tag` во frontend соответствует `tag_id` в базе. Перенос задач в Supabase будет в ЛР 6.

## Переменные окружения

Файл `frontend/.env.local` (не коммитится):

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

Образец без значений: `frontend/.env.example`. Secret key и пароль базы во frontend не используются.

## Адреса страниц

- `/` — переход к списку задач
- `/tasks` — список и фильтр
- `/tasks/t1` — карточка задачи (есть также t2–t5)
- `/tasks/new` — форма создания
- `/tasks/t1/edit` — форма редактирования
- `/tasks/missing` — задача не найдена
- `/unknown` — страница не найдена

## Текущие ограничения

Изменения задач не переживают обновление страницы. localStorage не используется. Задачи в базу не переносятся и анонимная запись не открывается. Авторизация и личные записи появятся в ЛР 6.

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

Если `npm ci` тянет пакеты с чужого адреса, выполните:

```bash
npm install --registry https://registry.npmjs.org/
```

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```
