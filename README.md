# Task Tracker

Практический курс веб-разработки: React + TypeScript + Node.js + Supabase  
Приднестровский государственный университет им. Т. Г. Шевченко

## Тема

**Task Tracker** — личный список задач со сроками и приоритетами.

Автор: Andrei Gaz  
Группа: указать при сдаче

## Основной сценарий

Task Tracker помогает студенту вести личные задачи. Пользователь добавляет задачу, указывает срок и приоритет, меняет статус и находит просроченные записи. Теги помогают группировать задачи.

## Стек

- React
- TypeScript
- Vite
- React Router
- позже: Node.js, Express, Supabase

## Версия Node.js

`24.15.0` (файл `.node-version` в корне репозитория)

## Что работает сейчас (ЛР 2)

- Общий layout и навигация
- Список из пяти демонстрационных задач
- Карточка задачи по адресу `/tasks/:id`
- Заглушка создания `/tasks/new` (форма будет в ЛР 3)
- Отдельные экраны для неизвестного адреса и отсутствующей записи

Записи сейчас хранятся в массиве `frontend/src/data/tasks.ts`. Это учебные данные, не база.

## Адреса страниц

- `/` — переход к списку задач
- `/tasks` — список
- `/tasks/t1` — карточка задачи (есть также t2–t5)
- `/tasks/new` — заглушка создания
- `/tasks/missing` — задача не найдена
- `/unknown` — страница не найдена

## Текущие ограничения

Формы создания и редактирования ещё не работают. HTTP, авторизация и Supabase появятся позже.

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

Если `npm ci` тянет пакеты с чужого адреса, выполните:

```bash
npm install --registry https://registry.npmjs.org/
```

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```
