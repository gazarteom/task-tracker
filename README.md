## Тема

**Task Tracker** — личный список задач со сроками и приоритетами.

Автор: Газ Артем Андреевич
Группа: ФТ24ВР62ИВ

## Основной сценарий

Task Tracker помогает студенту вести личные задачи. Пользователь добавляет задачу, указывает срок и приоритет, меняет статус и находит просроченные записи. Теги помогают группировать задачи.

## Стек

- React
- TypeScript
- Vite
- React Router
- позже: Node.js, Express, Supabase

## Версия Node.js

`24.15.0` (файл `.node-version` в корне репозитория)

## Что работает сейчас (ЛР 4)

- Создание, просмотр, изменение и удаление задач
- Одна форма для создания и редактирования, отмена без сохранения
- Проверка названия, срока и описания у завершённой задачи
- Фильтр списка по статусу
- Справочник тегов загружается по HTTP из `frontend/public/demo/tags.json`
- В форме тег выбирается из загруженного списка, свободный ввод убран
- Состояния загрузки, ошибки и пустого справочника, кнопка «Повторить»
- Пока тег не выбран или справочник недоступен, сохранить нельзя

В задаче хранится `id` тега (`study`), в списке выбора показывается `name` («Учёба»). Основные записи по-прежнему живут только в памяти вкладки: после обновления страницы возвращаются пять демонстрационных задач. Справочник при этом снова запрашивается по сети. База и Supabase ещё не подключены.

## Адреса страниц

- `/` — переход к списку задач
- `/tasks` — список и фильтр
- `/tasks/t1` — карточка задачи (есть также t2–t5)
- `/tasks/new` — форма создания
- `/tasks/t1/edit` — форма редактирования
- `/tasks/missing` — задача не найдена
- `/unknown` — страница не найдена
- `/demo/tags.json` — справочник тегов, который раздаёт Vite

## Текущие ограничения

Изменения задач не переживают обновление страницы. localStorage не используется. Отдельный сервер и ключи не нужны: справочник — JSON из `public`. HTTP-сервер приложения и Supabase появятся позже.

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

Если `npm ci` тянет пакеты с чужого адреса, выполните:

```bash
npm install --registry https://registry.npmjs.org/
```

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```
