# Task Tracker

Практический курс веб-разработки: React + TypeScript + Node.js + Supabase  
Приднестровский государственный университет им. Т. Г. Шевченко

## Тема

**Task Tracker** — личный список задач со сроками и приоритетами.

Автор: Артем Газ
Группа: указать при сдаче

## Основной сценарий

Task Tracker помогает студенту вести личные задачи. Пользователь добавляет задачу, указывает срок и приоритет, меняет статус и находит просроченные записи. Теги помогают группировать задачи.

## Стек

- React
- TypeScript
- Vite
- React Router
- позже: Node.js, Express, Supabase

## Версия Node.js

`24.15.0` (файл `.node-version` в корне репозитория)

## Что работает сейчас (ЛР 3)

- Создание, просмотр, изменение и удаление задач
- Одна форма для создания и редактирования
- Отмена без сохранения
- Проверка названия (3–100 символов), обязательный срок
- Предметное правило: завершённая задача должна иметь описание
- Фильтр списка по статусу со сбросом
- Пояснение, что данные живут только в памяти вкладки

После обновления страницы возвращаются пять демонстрационных задач из ЛР 2. База и Supabase ещё не подключены.

## Адреса страниц

- `/` — переход к списку задач
- `/tasks` — список и фильтр
- `/tasks/t1` — карточка задачи (есть также t2–t5)
- `/tasks/new` — форма создания
- `/tasks/t1/edit` — форма редактирования
- `/tasks/missing` — задача не найдена
- `/unknown` — страница не найдена

## Текущие ограничения

Изменения не переживают обновление страницы. localStorage не используется. HTTP, авторизация и Supabase появятся позже.

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

Если `npm ci` тянет пакеты с чужого адреса, выполните:

```bash
npm install --registry https://registry.npmjs.org/
```

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```
