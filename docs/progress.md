# История этапов

## Лабораторная работа 1 — Старт проекта на React и TypeScript

Тема: Task Tracker.

Результат: создан единый репозиторий `course-app` с пакетом `frontend` на Vite + React + TypeScript. Стартовый экран шаблона заменён на экран приложения: заголовок «Task Tracker», описание и пустой раздел «Мои задачи». Удалены логотипы и счётчик Vite. В `index.html` указаны `lang="ru"` и title приложения. Добавлены корневые README, `.gitignore`, `.node-version` и эта запись.

### Проверки

1. `node --version` → `v24.15.0` (зафиксировано в `.node-version` и README).
2. Проект создан командой `npm create vite@latest frontend -- --template react-ts`.
3. `npm run build` должен запускать `tsc -b && vite build` (см. `frontend/package.json`).
4. TypeScript в strict-режиме: если `appTitle` присвоить число вместо строки, сборка падает; после возврата строки сборка проходит.
5. После push на GitHub нужно клонировать чистую копию и выполнить `npm ci`, `npm run build`, `npm run dev` в `frontend`.

## Лабораторная работа 3 — Формы и локальное состояние

Результат: список задач хранится в `App`. Одна форма `TaskForm` создаёт и редактирует запись. Есть отмена, проверка названия и срока, правило для статуса «Готово», удаление с подтверждением и фильтр по статусу. В шапке указано, что данные живут только в памяти вкладки.

## Лабораторная работа 4 — Загрузка справочника по HTTP

Результат: теги больше не вводятся свободно. Справочник лежит в `frontend/public/demo/tags.json` и запрашивается через `fetch` из сервиса `frontend/src/services/tags.ts`. Хук `useTags` ведёт состояния loading, error и success. Форма использует загруженные варианты и не сохраняет запись без выбранного существующего тега. Повторная попытка не сбрасывает черновик.

### Проверки

1. Открыть `/tasks/new`. В Network есть GET `/demo/tags.json`. В Response массив из пяти тегов. Выбрать тег и сохранить.
2. Открыть редактирование: в select выбран сохранённый id, подпись — name.
3. Offline перед открытием формы: ошибка, кнопка «Повторить». После Online повтор сохраняет введённое название.
4. Пустой массив `[]` даёт «Тегов пока нет», сохранение недоступно.
5. Объект вместо массива, числовой id или повтор id дают ошибку структуры.
6. Уход со страницы во время загрузки не меняет список. Новый заход делает свой запрос.
7. CRUD, отмена и фильтр ЛР 3 работают. Отмена после смены тега не меняет запись.
8. Обновление страницы возвращает пять демонстрационных задач. «Повторить» перезагружает только справочник.
9. `npm run build` проходит, `public/demo/tags.json` попадает в сборку.
